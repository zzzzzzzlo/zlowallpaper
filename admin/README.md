# ZloWallpaper 管理工作台

独立的 HTML / CSS / JavaScript 管理端，源码与桌面客户端分别位于仓库 `admin/`、`frontend/`。不修改或依赖 Qt 客户端，不包含业务后端。

## 启动

需要 Node.js 22 或更新版本。运行页面不需要安装 npm 依赖，也不需要构建。

```powershell
cd D:\Codex\software\zlowallpaper\admin
npm start
```

浏览器打开 **http://127.0.0.1:4173**。Windows 也可双击 `StartAdmin.cmd`，然后打开上述地址。不能直接双击 `public/index.html`：ES modules 需要 HTTP 服务。

端口占用时：`$env:PORT = '4174'; npm start`。关闭启动服务的终端或按 Ctrl+C 停止服务。提供的静态服务只绑定 `127.0.0.1`，不能直接作为公网生产部署。

## 模拟模式

首次打开默认模拟模式，右上角始终标明当前模式。

| 账号   | 密码        | 结果                                   |
| ------ | ----------- | -------------------------------------- |
| admin  | Admin12345  | 验证通过，进入管理端                   |
| viewer | Viewer12345 | 登录成功但管理接口 403，不能进入管理端 |

模拟中提供 14 个商品和 3 个分类，可分页、创建、编辑、上下架。两份素材分别上传；模拟上传返回与契约一致的 `Asset`。上传文件、商品修改、模拟会话只在页面内存中保留，刷新或关闭页面即重置，不下载到业务后端、不写入桌面壁纸库。切换连接时本页面模拟商品仍保留，刷新才重置。

封面上限 4 MiB，真实原文件上限 10 GiB。**仅模拟上传的原文件额外限制为 64 MiB**，避免浏览器为计算 SHA-256 消耗过多内存；这个限制不发送给真实后端。模拟图片使用浏览器读取尺寸，模拟视频/GIF 的 fps 为样例值，不提供生产格式检测、视频分析或安全校验能力。预置 SVG 只是 UI 样例封面，不能通过上传接口作为壁纸上传。

目录下方“模拟验收工具”可切换空列表、503、401、403，并设置上传返回 READY / PROCESSING / FAILED。401 会退回登录，模拟过期开关自动恢复正常，便于重新登录；403 不伪装为 401。失败场景可切回正常并刷新。

## 真实接口模式

1. 后端实现冻结契约中的鉴权、分类、管理员接口，准备至少一个管理员与一个启用分类。
2. 后端允许页面来源的 CORS，详见 [联调与验收](docs/INTEGRATION.md)。
3. “连接设置”选择真实接口，根地址默认 `http://127.0.0.1:8080/api/v1`。
4. 登录真实管理员，按“上传封面 → 上传原文件 → 创建草稿 → 编辑 → 确认上架 → 确认下架”验收。

生产地址使用 HTTPS。根路径固定 `/api/v1`，禁止用户名密码、查询参数、片段；本机环回地址才允许 HTTP。模式或地址修改会清除本机会话、取消旧请求；尝试向旧服务注销，失败会明确告知。不会在真实接口报错时自动回退到模拟数据。

**没有新增接口或契约字段。** 上传响应字段是 `data.id`，创建商品时分别使用 `coverAssetId`、`originalAssetId`。后台角色来自服务器，前端不发送 `isAdmin` 或猜测 JWT 角色。

## 已完成范围

- 管理员登录与权限验证、令牌到期前刷新、登出。
- 商品分页（12 / 24 / 48 条），草稿 / 已上架 / 已下架，封面与媒体元数据预览。
- 分开上传封面和原文件；显示资产编号、状态、大小、尺寸；失败阻止保存。
- 创建草稿；编辑仅 PATCH 变化字段；上下架独立 PUT 并确认。
- 加载、空数据、连接错误、错误请求、限流提示、会话过期、权限不足状态；展示后端 requestId。
- 桌面与移动端布局、键盘焦点、原生模态对话框、减少动态效果设置。
- 凭证只在内存；localStorage 仅保存 API 地址和模式。请求禁止重定向与 cookie 携带，JSON 响应限 4 MiB，不自动重放写操作。

现有契约未提供异步资产状态查询。上传返回 PROCESSING 时会显示明确提示并禁止保存，**不会编造轮询接口，也不会将 PROCESSING 当作 READY**。相关待评审事项见 [契约缺口](docs/CONTRACT-GAPS.md)。

## 文件结构

```text
admin/
  public/
    index.html             页面与原生对话框
    styles.css             独立工作台样式与响应式布局
    assets/                自制 SVG 演示封面
    js/contracts.js        字段校验、金额转换、URL/文件边界
    js/api.js              真实 HTTP 请求、会话、上传、状态码校验
    js/mock-api.js         内存模拟传输；复用相同接口层
    js/app.js              页面状态与操作流程
  server.mjs               无依赖、本机静态 HTTP 服务
  StartAdmin.cmd           Windows 启动入口
  tests/                   Node 测试与测试专用 HTTP 夹具
  docs/                    契约缺口、后端联调和验收说明
```

## 验证

```powershell
npm test
```

测试用 Node 内置测试运行器，无需安装额外依赖。其中包含本机 HTTP 传输测试，并非只有模拟函数测试；这些测试服务不是实际业务后端。

可选浏览器验收工具：`npm ci`，然后 `npx playwright-cli -s=zlo-admin open http://127.0.0.1:4173 --browser msedge`。无 Edge 时按工具说明安装浏览器。验收记录和重跑步骤见 [INTEGRATION.md](docs/INTEGRATION.md)；截图等输出位于被 Git 忽略的 `output/playwright/`。
